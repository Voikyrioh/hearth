# InstallSettings

Organisme · `apps/desktop/src/components/organisms/InstallSettings.vue`

« Voir tous les réglages » dans l'installation (HRT-109, BR-FICHE-040) : sous la carte des questions, un bouton déplie dans la page la même liste que l'onglet « Réglages » sur les valeurs proposées (sans les réglages essentiels déjà posés plus haut ni ceux que la fiche impose), avec le compte « {n} réglage(s) différent(s) des valeurs proposées ». Un réglage touché part avec l'installation comme une réponse. « Importer des réglages » est présent mais inactif : l'agent lit le texte avec le format du jeu, ce qui demande un service installé.
