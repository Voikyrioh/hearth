# CommandBlock

Molécule · `apps/desktop/src/components/molecules/CommandBlock.vue`

Commande ou texte de configuration À RECOPIER (jamais exécuté), bloc défilable et focalisable, « Copier la commande » / « Copier le texte », « Copié » 2 s, échec dit sans bloquer.

- Props : `text`, `config`.
- HRT-78 : props facultatives `label`, `copyLabel`, `copiedLabel`, `failedLabel` (le droit de gérer les services a ses textes : « Commande à lancer sur le serveur », « Copiée »).
